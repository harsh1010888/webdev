# 🌟 Image Search Engine - Powered by Unsplash API 🚀  

This is a simple yet powerful **image search website** that allows users to find high-quality images using the **Unsplash API**. The project is built using **HTML, CSS, and JavaScript**, making it a lightweight and responsive web app.  

## 🔹 How It Works?  
1️⃣ Users enter a **search keyword** (e.g., "Mountains," "Cats," "Cars") in the search bar.  
2️⃣ The app fetches relevant images from **Unsplash** using API calls.  
3️⃣ The images are displayed dynamically on the page.  
4️⃣ The **"Show More"** button allows users to **load additional results** seamlessly.  

## 🔹 Technologies Used  
✅ **HTML** - For structuring the web page  
✅ **CSS** - To style the UI and enhance user experience  
✅ **JavaScript** - To handle API calls and display results  
✅ **Unsplash API** - For fetching high-resolution images  
✅ **Netlify** - For **free hosting and deployment**
