# 3d ball animation

this is a small html + css project that shows a glowing 3d-like ball in the center of the screen.  
when you hover your mouse over it, the ball slightly moves and rotates, giving it a smooth 3d effect.

## how it works
- html is used to create the basic structure (a container and a ball element)
- css handles the styling, colors, shadows, and animations
- when you hover over the ball, css transforms make it shift position and rotate
- a soft glow effect is created with shadows and blur

## how to run
- download or clone the project
- open `index.html` in any modern browser
- hover your mouse over the ball and watch it move

## why i made this
i wanted to try creating a fun little animation using only html and css, no javascript.
it’s a quick experiment to explore perspective, shadows, and smooth transitions.
