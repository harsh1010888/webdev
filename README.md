## 📌 About  
This is a simple **Weather App** that fetches real-time weather data using an API and displays temperature, location, and weather conditions.  

## ⚡ Features  
- 🌍 Get weather updates for any city  
- 📍 Auto-detect user location (optional)  
- 📊 Displays temperature, humidity, and wind speed  
- 🌑 Dynamic background based on weather conditions  

## 🛠️ Technologies Used  
- HTML  
- CSS  
- JavaScript  
- Weather API  
- Netlify for deployment  

## 🚀 How to Use  
1. Enter a city name in the search bar.  
2. Click the **Search** button to fetch weather details.  
3. View temperature, humidity, and wind speed instantly.
